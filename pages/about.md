# About Me

Hi, I'm **Durgaprasad Sunkara**, a DevOps and Platform Engineer based in Hamburg, Germany.

I work across Kubernetes, cloud infrastructure, CI/CD, automation and observability. I enjoy building the systems that help software move safely from a developer's machine into a reliable environment.

Most recently at **AIcoo GmbH**, I built and maintained the DevOps environment for an LLM-based product. The application included a FastAPI backend, frontend and PostgreSQL, deployed on k3s at Hetzner Cloud. I created 28 Kubernetes manifests, structured development and staging overlays with Kustomize, and built the delivery workflow using GitHub Actions, a self-hosted runner and GHCR.

I am currently completing an **MSc in Applied Data Science and Analytics at SRH University, Hamburg**, while working on my master's thesis with AIcoo. My thesis explores extracting project-related information from email collections using LLM-based and clustering approaches.

## Technical focus

- **Containers & orchestration:** Kubernetes, k3s, Docker, Helm, Kustomize
- **Cloud & infrastructure:** AWS, Hetzner Cloud, Terraform, Ansible
- **CI/CD:** GitHub Actions, GitLab CI, Argo CD, GHCR
- **Observability:** Prometheus, Grafana, Loki, Alertmanager
- **Development:** Python, FastAPI, PostgreSQL
- **Operations & security:** RBAC, secrets management, Trivy, recovery procedures
