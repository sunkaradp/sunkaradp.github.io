03 / FIELD NOTES

The interesting
part is the failure.

Selected engineering problems from the AIcoo internship: what failed, what the evidence showed, and what changed.

CASE 001 / DATABASE RECOVERY

Restore was not the finish line.

A 158 MB database restore exposed 61 schema-drift errors. The recovery path required rebuilding the database and replaying migrations rather than treating a successful file restore as proof of service recovery.

Recovery process / migration consistency
CASE 002 / WORKLOAD STABILITY

OOMKilled was a symptom.

Crash loops were traced to CPU throttling during startup. Startup behavior, CPU limits and probe timing were reviewed together, then resource and startup settings were adjusted.

Diagnosis / resource sizing / startup probes
CASE 003 / DELIVERY PIPELINE

Automation can break state.

Two pipeline defects could delete runtime secrets and run migrations without the required configuration. The workflows were corrected to protect runtime configuration and make migration execution explicit.

GitHub Actions / secrets / migration jobs
CASE 004 / SECRET HANDLING

Credentials need a lifecycle.

After a secret exposure, the response included purging affected Git history, rotating keys and moving secret material into Sealed Secrets rather than relying on deletion from the latest file alone.

Incident response / rotation / Sealed Secrets
