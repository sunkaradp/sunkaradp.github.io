Workload configuration

A Deployment defines the desired replicas and the container configuration. Readiness should reflect whether the application can serve traffic, not merely whether its process started.

apiVersion: apps/v1
kind: Deployment
metadata:
  name: backend
spec:
  replicas: 2
  selector:
    matchLabels:
      app: backend
  template:
    metadata:
      labels:
        app: backend
    spec:
      containers:
        - name: backend
          image: OWNER/backend:TAG
          resources:
            requests:
              cpu: 100m
              memory: 128Mi

Example values are placeholders. Validate probes, resource requests, image tags and namespace configuration for the application before applying manifests.
