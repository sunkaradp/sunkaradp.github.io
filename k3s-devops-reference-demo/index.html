Chapter 01 / Deployment

A workload should declare its contract.

A Deployment captures desired replicas and container configuration. Readiness should represent the application's ability to serve traffic, not simply whether its process has started.

apiVersion: apps/v1
kind: Deployment
metadata:
  name: backend
spec:
  replicas: 2
  selector:
    matchLabels:
      app: backend
  template:
    metadata:
      labels:
        app: backend
    spec:
      containers:
        - name: backend
          image: OWNER/backend:TAG
          resources:
            requests:
              cpu: 100m
              memory: 128Mi
Replace placeholders and validate probes, resources and image references against the application before applying.
