AlertScope

An Alertmanager webhook that gathers Prometheus metrics, Loki logs and Kubernetes pod context, then produces an evidence-based first-pass incident summary for Slack. Includes a local failure demo, Grafana dashboard and cloud identity setup using workload identity rather than static keys.

CF / 02
Controlled remediation

Kubernetes incident remediation

A k3s remediation service with predefined runbooks and a policy ceiling. The model can recommend from named actions; it cannot run arbitrary shell commands. Observe mode and dry-run are the safe defaults. Cluster deployment, approval integration and chaos verification remain roadmap work.

Python · FastAPI
Alertmanager · RBAC

CF / 03
Preventive signals

Kubernetes platform intelligence

An observe-only operator experiment that uses Prometheus memory metrics and a simple regression trend to estimate possible node memory pressure, then emits a Kubernetes Warning Event. Tested on Minikube; predictions are investigation signals, not guarantees.

Kubernetes Operator

Release risk analysis

Deployment Dash Intelligence

A read-only Kubernetes manifest reviewer. It checks submitted YAML for configuration and container-security risks, explains findings with manifest paths and offers recommendations. Its score is a heuristic prioritisation signal, not a probability of outage or a compliance certification.
