I'm a DevOps engineer based in Hamburg with over 3 years of experience building and running cloud infrastructure, CI/CD pipelines and monitoring. Lately my work has moved toward the point where infrastructure meets machine learning.

At an AI startup in Hamburg I built and operated the DevOps environment for an LLM product: a k3s cluster on Hetzner Cloud with separate dev and staging environments, Kustomize manifests, Sealed Secrets, GitHub Actions on a self-hosted runner, and Prometheus, Grafana and Loki for monitoring. I wrote the runbooks that go with it.

I also build data and ML pipelines. On a multi-agent RAG project I implemented data loading, embeddings and vector database integration with pgvector. My master's thesis at SRH Hochschule Hamburg, in progress, applies the same MLOps-style approach to extracting and evaluating project emails from the Enron corpus.

Before that I worked as a DevOps engineer in Bengaluru. I cut GitLab CI/CD deployment time by 30% and automated the setup of 15 EC2 servers with Terraform, bringing it from two days down to two hours.

I'm especially interested in running ML systems reliably in production, where pipelines, monitoring and infrastructure have to hold up under real load.
