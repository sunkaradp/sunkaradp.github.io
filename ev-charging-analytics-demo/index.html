The current repository documents synthetic event generation and Kafka ingestion, a streaming consumer with rolling summaries, and an Airflow batch workflow for cleaning and aggregation.

Sample data is generated locally by this page; it is not connected to Kafka, Airflow, BigQuery or a live charging network. This is a collaborative project. My documented contributions include producer reliability, reusable batch transformations, tests and Python CI. See the repository history for attribution.
